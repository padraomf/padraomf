PADRÃO MF — VERSÃO 8.4 — FONTE E HOME CONFORME REFERÊNCIAS

ABRIR NO WINDOWS
1. Extraia o ZIP inteiro em uma pasta nova.
2. Abra INICIAR-SITE.bat. Ele usa o PowerShell e o .NET do Windows, sem alterar políticas.
3. O navegador abre o site local. Mantenha a janela do iniciador aberta.
4. Feche a janela quando terminar.
O iniciador foi incluído para servir o site por HTTP, necessário para o YouTube
identificar a página. Não foi executado em um Windows nesta sessão.

MAC/LINUX
Com Python 3 instalado, execute: python3 scripts/serve.py
Ou use a versão publicada em sua hospedagem.

DUPLO CLIQUE EM INDEX.HTML
As artes e os vídeos MP4 locais funcionam por duplo clique. O YouTube pode recusar
players sem identificação da página (erro 153) quando o HTML é aberto como arquivo.
Nessa situação, use o iniciador ou a versão hospedada.
A internet é necessária para os players do YouTube, incluindo no modo local.

DOMÍNIO E LINKS
Os links internos são relativos. Não há domínio de plataforma fixo em CONFIG.siteUrl.
Ao hospedar, os botões WhatsApp usam automaticamente o endereço atual do seu site.
No computador, sem domínio configurado, a mensagem inclui a identificação do projeto
sem enviar um endereço local que outra pessoa não conseguiria abrir.
Para um endereço público sem nome de plataforma, conecte seu próprio domínio.
Não foi inventado ou registrado um domínio nesta atualização.

COMPARTILHAMENTO E TROCA DE DOMÍNIO
Para gerar capas de compartilhamento com seu domínio, preencha CONFIG.siteUrl em
assets/data.js e execute scripts/build-pages.py com Python + Pillow, ou execute:
python scripts/build-pages.py --site-url https://SEU-DOMINIO
Substitua SEU-DOMINIO pelo endereço real. Publique novamente todos os HTMLs e assets.
Metadados no pacote portátil usam caminhos relativos até o domínio ser configurado.
O sitemap.xml só é gerado depois de informar um domínio real; o pacote não fixa
um endereço de plataforma. Veja INDEXACAO.txt antes de publicar em outro domínio.
A página precisa estar pública para leitores de prévias de WhatsApp e outras redes.
Cada plataforma escolhe qual das imagens declaradas exibir.
